# Review format (apply)

Short, specific, every verdict citing a DNA line. No preamble, no praise padding.

## Before rendering

```
Plan: <what the work is, one line>
Leans on: <DNA line>, <DNA line>
At risk of: <section 3 rejection>, <section 3 rejection>
Brand system: <name> governs tokens | none applies
```

Four lines. If "Leans on" is empty, stop and ask what the piece is for.

## After rendering

```
Calibration
1. <pass|fail> <verdict in one sentence, citing the line it rests on>
2. ...
3. ...
4. ...
5. ...

Rejections committed
- <section 3 bullet>: <the element that commits it>
(or "none")

Smallest change
- <one change per failure, imperative, concrete>

DNA was silent on: <the decision(s) made without coverage, or "nothing"> -> extract
```

## Verdict sentences

Good: "Fails 1: remove the card borders and the three columns collapse into one column of text."

Good: "Passes 2: green appears once, on the paid block."

Not good: "The hierarchy could be stronger." (no line cited, no element named, no change)

Not good: "Great use of whitespace!" (a pass needs no praise; say "passes" and move on)

## On a clean pass

One line: "Passes all five, commits no rejection." Stop. Do not append suggestions.
