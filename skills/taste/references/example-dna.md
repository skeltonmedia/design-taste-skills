# Taste DNA: Harbor

> Invented example. Harbor is a fictional two-person studio making a scheduling tool for freelancers. Every date, decision, and name below is made up to show what a filled file reads like. Do not copy any line into a real subject's file.

## 0. The governing rule

> **The calendar is the interface.** Anything that is not a day, a block, or the text inside one must earn its pixels. If a feature needs chrome to be found, the feature is in the wrong place.

## 1. The named aesthetic

**Quiet Instrument.** Plain enough to disappear during work, precise enough to trust with money, warm enough that a Sunday evening in it does not feel like a spreadsheet.

| Drop | Result |
|---|---|
| Plainness | Dashboard theater. Widgets, badges, a sidebar nobody opens. |
| Precision | A lifestyle app. Pleasant, not something you bill clients from. |
| Warmth | A terminal. Correct, cold, abandoned by March. |

## 2. What the decisions reveal

| Decision | Date | What it reveals |
|---|---|---|
| Single humanist sans with a true italic; the monospace face dropped from the UI after two weeks | 2026-03-11 | Wanted technical credibility, found that the mono made the calendar feel like a log file. Credibility comes from alignment, not from a coding font. |
| Week view ships with no borders between days; the column gutter does the work | 2026-03-20 | Structure from spacing, not lines. Borders were tried and declined the same day. |
| One accent (a deep green) marks paid time only; everything else is ink and paper | 2026-04-02 | Color carries one meaning. "If green means money, green cannot also mean selected." |
| Onboarding is three screens, no illustration, one real calendar with sample blocks | 2026-04-18 | Evidence over decoration. The sample week is the pitch. |
| Kept a larger, bolder clock face on the mobile day view despite the restraint rule | 2026-05-06 | Function beats consistency. The day view is read at arm's length while walking. |
| Declined a "celebrate your first invoice" confetti moment | 2026-05-22 | No performed enthusiasm. The invoice going out is the celebration. |

## 3. What gets rejected

- **Chrome that explains itself.** Tooltips, coach marks, and empty-state illustrations that tell the user what a calendar is. (source: 2026-04-18, rejections.md)
- **Borders doing hierarchy's job.** Lines between things that spacing already separates. (source: 2026-03-20)
- **A second accent.** Any color competing with green for attention. (source: 2026-04-02)
- **Performed enthusiasm.** Confetti, exclamation marks in UI copy, badges for routine actions. (source: 2026-05-22)
- **Generic SaaS composition.** Centered hero, three feature cards, a gradient blob. The landing page comps that had it were declined. (source: 2026-05-30, rejections.md)
- **Monospace as a mood.** Using a coding font to signal "technical". [inferred] from 2026-03-11; confirm.

## 4. Appetite

Where effort goes without being asked:

- Spacing rhythm and type size across the week, day, and month views. The first lever and usually the last.
- The sample data. Real-looking client names, honest block lengths, a week that reads true.
- Keyboard flow. Every scheduling action reachable without the mouse. [inferred] from the 2026-04 changelogs; confirm.

Where it will not go:

- Illustration, mascots, custom icon sets. System icons are fine.
- Motion beyond a block settling into place. Nothing bounces.
- Themes. One light, one dark, no accent picker.

## 5. The calibration test

1. **Remove every border and fill. Does the week still read?** If not, the gutter is wrong.
2. **Is green doing exactly one job?** Paid time, nothing else.
3. **Could the sample data be a real freelancer's week?** If the names are "Client A" and every block is one hour, it fails.
4. **Does any copy on the screen explain the product to itself?** If yes, delete it.
5. **Would a user with the app open on a Sunday night feel watched or calm?** Calm passes.

## 6. Known tensions

- **Dark mode warmth.** The warm paper tone of light mode has no agreed equivalent in dark; the current dark theme reads cold (section 1, "Warmth"). Open since 2026-05-14. Options on the table: warm the dark surface two steps, or accept a cooler dark and say so in section 1.
- **Marketing site vs product.** The product refuses the centered hero; the marketing site draft uses one (2026-05-30 rejection). Ruled 2026-06-14: the site follows the product. "The calendar is the interface" applies to the pitch too.

## 7. Proposed

- **Numbers align before they decorate.** Seen three times (library keys `tabular-figures`, 2026-04-09, 2026-05-02, 2026-06-01). Would join section 4, appetite. Awaiting promotion.
